# Flashcard App (Static Deck)

## About
Flashcard App is a simple study application built using HTML, CSS, and JavaScript. It displays a fixed collection of questions and answers that users can flip through while learning.

## Features
- 10 predefined flashcards
- 3D flip animation
- Previous and Next navigation
- Progress indicator
- Shuffle flashcards
- Responsive design
- Keyboard navigation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
flashcard-app/
├── index.html
├── style.css
└── script.js
```

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start exploring the flashcards.
